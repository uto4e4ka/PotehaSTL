# Three.js Scene → GLB / STL

Расширение для Chrome: находит на странице сцену three.js и сохраняет её в `.glb` или `.stl`.

## Установка

1. Распакуйте архив в папку.
2. Откройте `chrome://extensions` и включите **Режим разработчика** (справа вверху).
3. Нажмите **Загрузить распакованное** и выберите папку `three-ripper`.
4. Закрепите иконку на панели расширений.

## Использование

Откройте страницу с 3D-моделью, дождитесь, пока она отрисуется, нажмите на иконку и выберите формат:

- **GLB**: геометрия, нормали, UV, вершинные цвета, материалы и текстуры.
- **STL** (бинарный): только треугольники, для 3D-печати. Модель поворачивается из Y-up (three.js) в Z-up (слайсеры), чтобы стояла вертикально. Единиц в STL нет, слайсер прочитает размер в миллиметрах, поэтому масштабируйте модель под нужную высоту. Высоту в исходных единицах покажет сводка.

Файл скачается, а в углу страницы появится сводка: сколько мешей, треугольников и текстур попало в файл.

Если сцена не нашлась, перезагрузите страницу. После установки расширение ловит сцены с момента загрузки страницы, а на уже открытых вкладках этого не происходит.

## Как ищется сцена

1. `hook.js` выполняется до скриптов страницы и подставляет `window.__THREE_DEVTOOLS__`. three.js сам сообщает туда о каждой новой `Scene`.
2. Проверяются глобальные переменные (`scene`, `app.scene`, `viewer.scene`…).
3. Идёт обход React-фибера от каждого `<canvas>` по хукам компонентов (react-three-fiber и самописные React-вьюеры).

Из найденных сцен выбирается та, где больше всего треугольников.

## Что экспортируется

- Все видимые меши, запечённые в мировые координаты. Квантованные позиции (Uint16/Int8, normalized, interleaved) деквантуются.
- Скиннинг и морфы в текущей позе, если в three.js есть `getVertexPosition` (r151+).
- `InstancedMesh`: каждый инстанс становится отдельным узлом.
- Нормали, UV (с учётом `offset`/`repeat`/`flipY`), вершинные цвета.
- Мульти-материалы по группам, базовый цвет, metalness/roughness, `map` в PNG.

## Ограничения

- Не экспортируются анимации, скелет и иерархия: геометрия запекается в одну позу.
- Текстуры с чужого домена без CORS «отравляют» canvas, поэтому пропускаются. Сжатые текстуры (KTX2/Basis) тоже не достать.
- Внешний вид кастомных `ShaderMaterial` не переносится, сохраняется только геометрия.
- Сцены на Vue или Angular без глобальных переменных находятся только через хук, так что страницу нужно перезагрузить.

Используйте расширение для своих моделей и для отладки. Чужие ассеты обычно защищены лицензией.
